# Summit Ridge Landscaping

A modern, high-conversion landing page for a landscaping company based in Austin, Texas.

## Features
- **Responsive Design**: fully responsive layout that looks great on mobile, tablet, and desktop.
- **Scroll Animations**: smooth reveal animations on scroll.
- **Video Scrubbing**: the hero video scrubs frame-by-frame based on scroll position.
- **Modern UI**: utilizes glassmorphism, fluid typography, and premium color palettes.
- **Custom Fonts**: uses Abril Fatface and Source Sans 3 for a premium aesthetic.

## Local Development
To run this project locally, simply serve the directory with any static file server. For example, using `npx`:

```bash
npx serve .
```

Then open `http://localhost:3000` in your browser.
